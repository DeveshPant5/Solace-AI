# Solace app

React Native + Expo (SDK 58) app for Solace. See the project README one level up for features, setup and building.

- `npx expo start --web` to preview in a browser
- `API_URL=http://<wifi-ip>:4000 npm run build:apk` to build an installable APK
- Routes live in `src/app/`, shared UI in `src/components/`, API/notifications in `src/lib/`, content in `src/content/`, theme in `src/theme/`.
